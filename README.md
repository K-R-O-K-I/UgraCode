# Ясна

Веб-приложение для детской столярной мастерской. Python 3.14, Django 5.2, PostgreSQL 17, Django-шаблоны, CSS и JavaScript.

- **Мастер** видит сводку дня, открывает расписание на день, неделю или месяц, создаёт и отменяет занятия. В карточке занятия видны участники и отметки «Был» и «Пропуск».
- **Семьи** мастер создаёт и находит по имени семьи или ребёнка. Он может посмотреть профили детей и выдать персональную ссылку. Родитель входит по этой ссылке без пароля и сам управляет профилями детей.
- **Запись** списывает одно занятие с абонемента, действующего на дату урока. Своевременная отмена возвращает занятие. Поздняя отмена требует подтверждения и освобождает место без возврата. При отмене урока мастером занятие возвращается активным участникам.
- **Оплаты и чеки** мастер учитывает наличные и переводы и прикрепляет чеки к оплатам. Семья открывает их в отдельной вкладке «Чеки». В деморежиме родитель может оплатить абонемент или отдельную запись.
- **Документы** мастер загружает в PDF или UTF-8 TXT до 5 МБ. Перед оплатой родитель подтверждает каждый документ. Система сохраняет версию документа и время согласия.
- **Уведомления и отчёты** включают сообщения о записи и отмене, напоминание семье об одном оставшемся занятии, историю действий и выгрузки CSV.

## Локальный запуск

Актуальная версия находится в ветке `main`. Docker для локального запуска не требуется. Запустите PostgreSQL и в pgAdmin или psql подключитесь к базе `postgres` администратором. Если роли и базы ещё нет, выполните по очереди, подставив свой пароль:

```sql
CREATE ROLE yasna WITH LOGIN PASSWORD 'ваш-локальный-пароль';
CREATE DATABASE yasna OWNER yasna;
```

В PowerShell:

```powershell
git clone https://github.com/K-R-O-K-I/ClaudeCode.git
cd ClaudeCode
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
.\.venv\Scripts\python.exe -c "import secrets; print(secrets.token_urlsafe(50))"
```

Запишите сгенерированный ключ в `DJANGO_SECRET_KEY` в файле `.env`. Укажите `POSTGRES_PASSWORD` и проверьте остальные параметры подключения. Для локального запуска оставьте `DJANGO_DEBUG=true` и `127.0.0.1` в `DJANGO_ALLOWED_HOSTS`. Чтобы показать тестовую оплату, добавьте `PAYMENT_MODE=demo`.

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py setup_master
# Для демонстрации на отдельной тестовой базе:
.\.venv\Scripts\python.exe manage.py demo_data
.\.venv\Scripts\python.exe manage.py family_demo
.\.venv\Scripts\python.exe manage.py prepare_showcase
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8001
```

На Linux и macOS используйте `python3 -m venv .venv` и `.venv/bin/python` вместо пути Windows. Если проект уже настроен, после получения новой версии примените миграции и перезапустите сервер.

Откройте [кабинет мастера](http://127.0.0.1:8001/) с учётными данными из `setup_master`. В разделе «Семьи» выберите семью и выдайте ссылку. Откройте её в другом профиле браузера, чтобы проверить кабинет родителя. Команда `prepare_showcase` дополняет демопрофили, создаёт занятия и записи и публикует пример согласия. Для реальных оплат загрузите утверждённый текст согласия.

## Оплата и доступ

В режиме `demo` деньги не списываются. Для оплаты абонементов через ЮKassa предусмотрены `PAYMENT_MODE=yookassa`, `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`, публичный HTTPS-адрес `PUBLIC_BASE_URL` и webhook `/family/webhook/`. Реальные платежи не проверены. Оплата отдельной записи доступна в деморежиме.

Персональная ссылка содержит случайный ключ с 256 битами энтропии. В базе хранится его хеш. Ссылка действует 90 дней. Выдача новой ссылки закрывает доступ по старой ссылке и открытым через неё сеансам. Семья видит только свои записи, профили и чеки. При публичном запуске используйте HTTPS и `DJANGO_DEBUG=false`.

Уведомления доступны внутри личных кабинетов. Команда `manage.py family_reminders` сверяет остатки, сроки действия абонементов и открытые счета. Для ежедневной сверки добавьте её в системный планировщик.

## Структура и проверки

- `config/` — настройки и маршруты Django.
- `accounts/` — семьи, дети, ссылки для входа и доступ к аватаркам.
- `dashboard/` — кабинет мастера, расписание, посещения, оплаты и управление документами.
- `families/` — кабинет родителя, запись, оплата и хранение согласий.
- `static/` — общие стили, логотип и навигация без полной перезагрузки.
- `Архитектура/` — проектные материалы. Фактическую схему БД определяют Django-модели и миграции.

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run
.\.venv\Scripts\python.exe manage.py test
```

Для тестов нужна локальная роль PostgreSQL с правом создавать тестовую БД (`CREATEDB`). Её можно задать через `POSTGRES_USER` и `POSTGRES_PASSWORD` текущего процесса. `.env`, PostgreSQL и файлы из `private_media/` переносятся отдельно от Git.
